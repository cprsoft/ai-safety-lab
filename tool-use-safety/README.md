# Tool-Use Safety

Agent'ın e-posta, dosya sistemi, terminal, API, tarayıcı, takvim, GitHub gibi araçları kullanırken güvenli sınırlandırılması.

**Trust Tier:** 2

**Kapsam içi:** Araç kategorisi bazlı risk deseni, minimum güvenlik sınırı önerisi (örn. "irreversible action önce onay gerektirir").

**Kapsam dışı:** Belirli bir aracın/üründe zafiyet teşhiri, çalışan bypass kodu.
