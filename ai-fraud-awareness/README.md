# AI Fraud Awareness (Builder/Product Angle)

AI ürünlerinin scam, manipülasyon, impersonation, deepfake veya phishing üretimini kolaylaştırmaması için ürün geliştirici güvenlik notları.

**Trust Tier:** 2 (genel önleyici tasarım notu) veya 3 (deepfake/manipulation-spesifik — misuse-sensitive)

**Önemli:** Bu klasör **builder açısını** ele alır — "AI ürünün bunu üretmesini nasıl önlersin". Son kullanıcı dolandırıcılık farkındalığı (`siber-savunma-atlas/threat-trend-reports/`) burada işlenmez.

**Kapsam içi:** İçerik moderasyon tasarımı, kötüye kullanım tespiti, rate-limiting/guardrail prensipleri.

**Kapsam dışı:** Deepfake/scam üretim adımı, gerçek dolandırıcılık metni örneği.
