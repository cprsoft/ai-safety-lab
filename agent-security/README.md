# Agent Security

AI agent mimarilerinde permission, tool access, sandboxing, approval flow ve audit logging riskleri.

**Trust Tier:** 1 (checklist/kavramsal) veya 2 (risk kartı, daha derin analiz)

**Kapsam içi:** Over-permissioned agent riski, sandboxing prensipleri, audit log tasarımı, approval flow desenleri.

**Kapsam dışı:** Çalışan bir agent'ı atlatma/manipüle etme adımı, gerçek bir ürünün zafiyetinin teşhiri.
