# Prompt Injection Awareness

Prompt injection kavramının ve savunma yaklaşımlarının farkındalık odaklı anlatımı.

**Trust Tier:** 3 — **misuse-sensitive**, maintainer review zorunlu

**Kapsam içi:** Kavramın mantığı (modelin güvenilir/güvenilmez girdiyi ayırt edememesi), genel savunma desenleri (input/output ayrımı, yetki sınırlandırma).

**Kapsam dışı:** Çalışan injection payload'u, kopyala-yapıştır kullanılabilir herhangi bir saldırı metni. Bkz. `../methodology/safe-ai-scenario-writing.md`.
