# Data Leakage Prevention

LLM uygulamalarında PII, secrets, log, memory, RAG kaynağı ve output leakage riskleri.

**Trust Tier:** 1 (kavramsal genel not) veya 2 (RAG/pipeline-spesifik daha derin analiz)

**Kapsam içi:** Sızıntı kategorileri, önleyici kontroller (output filtering, RAG kaynak izolasyonu, log redaction).

**Kapsam dışı:** Gerçek sızdırılmış veri örneği, belirli bir ürünün zafiyetinin teşhiri.
